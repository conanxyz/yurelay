## 🚀 安装与开始使用

需要 **macOS 14 或更新版本**。安装包发布后，可从 [Releases](https://github.com/conanxyz/yurelay/releases) 下载 `.dmg`，打开后将 Yurelay 拖入“应用程序”。Apple Silicon 选择 `aarch64`，Intel 选择 `x64` / `x86_64`；页面暂无安装包时，可按 [README 的本地构建步骤](../README_cn.md#development) 从源码构建。Homebrew 安装渠道尚未提供。

1. 为划词开启**辅助功能**权限，为截图开启**屏幕录制**权限。
2. 在「设置 → 服务」选择系统词典，或配置自己的模型服务。
3. 捕获一段文字，等原文就绪后按 `D` / `S` 或点击“翻译 / 查询”开始。
4. 若提示已有密钥需要授权，点击“授权并继续”，按 macOS 系统提示完成授权。

### 新手引导、设置与模型入口

首次启动会显示“权限准备 → 选择服务 → 基础操作”。可按需要授权，也可选择“稍后设置”；已完成或跳过的引导不会在每次启动时重复弹出。标题栏的 **齿轮**、应用菜单、托盘和 `⌘,` 都可打开设置，**问号**或「设置 → 使用帮助」可重播教程。引导打开时再次点击标题栏问号，与“稍后设置”相同：记住跳过状态并返回阅读，保留当前原文。空白阅读页不再重复显示引导横幅。

点击翻译窗口的服务／模型名称，会直接打开对应服务配置。修改模型后点击“保存设置”；修改快捷键请打开「翻译与快捷键」。系统词典适合单词和短语，整句翻译需要翻译服务；语境解析与表达/回复需要支持生成的模型服务。填写配置不代表连接已验证，可主动使用固定示例测试连接。

基础教程使用独立演示，不发送网络请求、不覆盖原文、不改变剪贴板或写入历史。教程显示当前快捷键，而非固定假设默认键位。

主窗口默认 520 × 560（macOS 逻辑像素）。原文、译文、引导和生词内容变化不会调整窗口尺寸；超出部分滚动查看。手动拖动调整的尺寸会保存并在下次启动恢复，放大后恢复到放大前大小。窄窗的生词区排在阅读内容下方，不遮挡原文或改变阅读列宽度。

标题栏图钉用于置顶：开启后，切换到其他应用时窗口仍保持可见，不执行失焦自动隐藏；取消置顶后恢复原有自动隐藏设置。按 Esc 或主动点“收起”仍可隐藏已置顶的窗口。

基础引导提供“智谱免费模型”快捷配置：注册智谱开放平台，在 API Keys 页面创建“模型标准 API”的 Key，粘贴后点击“保存并使用”。默认预设 `glm-4.7-flash`，无需填写接口地址或模型；Coding Plan Key 不适用于此入口。高级设置仍可更改模型，已有配置不会自动替换。

### 首次打开与权限说明

当前工作流生成的是临时签名、未经 Apple 公证的开发包。确认来源可信后，可按 [Apple 官方说明](https://support.apple.com/zh-cn/102445)，在「系统设置 → 隐私与安全性」选择“仍要打开”。提示文件损坏时，应先核实文件与发布来源。

辅助功能用于跨应用取词，屏幕录制用于截图；仅手动输入、粘贴或本地查词不需要这两项权限。它们与应用签名、公证和钥匙串访问分别管理。更新开发包后，必要时在 Yurelay 的权限页面查看恢复指引。

原文和译文的阅读区底部都有调高柄，可拖动或用上下方向键调整。宽窗口保持 24px 边距并默认铺满可用空间，左右阅读区及底部手柄对齐；拖动任一手柄会联动调整两栏，共同的高度比例单独保存。窄窗口上下排列，仍保留各自的调高设置。展开“表达/回复”会向下延伸，不压缩上方阅读区。双击手柄或按 Home 恢复默认铺满；手动比例在收起展开、重新翻译和重启后保留。调整只影响内部阅读区，长内容在区域内滚动，外层窗口保持原尺寸。

## 阅读与回复

1. **获取文字。** 划词、截图，或直接输入、粘贴。
2. **检查原文。** 默认以阅读态显示；点击铅笔编辑，确认 OCR 和整理结果。
3. **主动翻译。** 等原文就绪，松开快捷键，再单独按 `D` / `S` 或点击“翻译”。

捕获或 OCR 进行中、按键连发、编辑框内输入和输入法组合输入不会触发翻译。阅读模式支持段落、标题、列表和代码块，也可切换纯文本，分别复制译文或 Markdown。

默认切换到其他应用时收起结果窗口，可在「界面与显示」中关闭。隐藏窗口不会中断已开始的翻译；返回原应用后可以继续取词或截图。

### 整理原文与阅读结构

- **追加原文：** 开启“追加”可合并最多十段划词或截图；编辑或切换草稿会暂停追加。
- **规范断行：** 捕获后默认在本机保守整理 PDF 句中换行；确实改变文本时可撤销。这不等同于语法纠错或任意改写。
- **表格与公式：** OCR 坐标足够明确时，可手动应用表格整理并对照原图。公式在本地排版，失败时保留源码；可选“保留表格与公式结构”要求模型保留列、数字、单位和可辨认公式，但不能补回 OCR 已遗漏的符号。

### 朗读原文与译文

原文和译文左下角的扬声器按钮可直接使用本机语音朗读，不必等待词典或生词候选。再次点击可停止，切换到另一段朗读会停止上一段。译文按可读文本朗读；声音取决于 macOS 已安装的语言。

### 解析语境与表达/回复

选中片段后，主动生成语境解析；需要回应时，打开“表达/回复”，用母语写下想表达的意思，再点击“生成回复”。回复结果直接显示“原文”和“译文”：原文是按当前服务与原文语种生成的回复，译文使用当前翻译语言。 回复应保留你在“回复意图”中填写的人名、事实和承诺；原文中的示例答案不是你的身份或要表达的内容。输入追问时，生成的是你发给对方的问句，不会替对方作答；陈述和请求也会保持原本的表达意图。回译只针对生成的回复，不是重新翻译整段原文。若模型正常结束后漏掉译文，应用会保留回复原文并尝试补全一次译文，期间仍可复制原文或停止；补全失败时会给出提示。

解析与回复都可以独立停止、重新生成并回看历史。回复框右上角的复制图标只复制回复原文，不含译文、标签和历史内容，也不会自动粘贴或发送。原文或意图改变后，旧回复会标记为过期，需主动重新生成。

## 📚 查词与语境生词本

**只想查一个词？** 在「设置 → 服务」把 **macOS 系统词典**设为默认，即可查询本机已启用词典中的单词和短语，无需 API Key。选择模型服务时，Yurelay 会按输入内容使用词典或段落提示词。

遇到整句或段落，系统词典会提示为当前查询选择已配置的翻译服务；选好后按 `D` / `S` 或点击“翻译 / 查询”才会开始翻译，全局默认服务保持不变。

短词的自动语言检测可能没有足够把握，例如 `Analytics`。检测结果未知时仍可点击查看本机词典。主动点击“收录”即可保存选中的词，语种未确定或暂无词典释义都不会阻止收藏。查词本身不会自动收录。

**想把表达留下来？** 点击或划选英语原文中的单词，先看本机词形还原和词典预览，再点击“收录”。也可以从模型提炼的英语候选中收录。

- 一词保留多段原句和可用释义，同一句重复收录不会重复计数。
- 支持个人笔记、学习中 / 已掌握状态、词条与语境搜索。
- 候选到达不会自动展开侧栏；打开侧栏时保持原文阅读位置，手动收起后不被迟到数据重新打开。
- 侧栏提供英式 / 美式及慢速朗读，使用本机可用语音。
- 可导出 **CSV、Markdown 或 Anki TSV**，继续整理和复习。

“阅读原文”可在本地标记正在学习的单词和短语，点击即可查看旧语境或标为已掌握。匹配本身不再次收录，也不增加计数。

<a id="history"></a>

## 🕘 读过的内容，随时找回

在「设置 → 历史记录」按原文、译文或来源查找，回看划词、截图与手动输入的记录。可以查看原文、修正后的文本、已保存截图和译文，复制内容或重新打开翻译框。

历史默认保留 **7 天**，也可指定天数、永久保存或不保存到磁盘。已经明确收录的生词独立保存，方便长期积累。

解析和回复沿用父记录的保留时间；独立结果采用相同的保留设置。辅助操作历史最多保留 40 个操作、合计 32 MiB，每个操作保留五次旧尝试。单次放行的敏感结果仅驻留内存；重启不会重发未完成请求。

## 🔌 使用自己的翻译服务

| 服务 | 配置方式 |
| :--- | :--- |
| macOS 系统词典 | 无需密钥，使用本机已启用的词典 |
| 智谱 AI、硅基流动、DeepSeek、通义千问 | API Key + 模型名称 |
| Gemini、OpenAI、Claude | 对应平台的 API Key + 模型名称 |
| MiniMax | 选择中国区或国际区，使用对应区域的密钥 |
| OpenRouter | API Key + 模型 ID |
| 有道智云 | 应用 ID + 应用密钥 |
| 自定义服务 | OpenAI 兼容地址 + 模型名称，按服务要求填写密钥 |

打开「设置 → 服务」，选择服务、填写配置、测试连接，最后设为默认并保存。服务预置了部分模型候选，例如智谱 `glm-4-flash-250414`；费用、免费额度和可用性以服务商为准。测试连接也会发送固定示例文本，可能计费。

### 自动备用与提示词设置

连接验证与已保存的地址、模型和凭据版本绑定，七天后过期。自动备用服务默认关闭；开启后，所有已配置且能力兼容的服务默认成为候选，正文出现前最多尝试三次，无需逐个勾选或预先测试。连接测试仍提供状态信息。这可能产生多家供应商的费用；单次放行的敏感请求不自动转移。

新翻译默认使用设置中保存的服务，结果旁显示实际生成它的服务，包括自动切换后的备用服务。自动备用不会改写默认服务或这次请求原先指定的首选服务。主阅读窗口不再单独显示“下次服务”选择器。

“设置 → 提示词”分别管理翻译与回复提示词。服务默认引用全局设置，也可自定义覆盖；已有的服务翻译提示词会保留。修改后需要保存，不会自动重发已有请求。

| :--- | :--- |
| 划词取词 | `Option + D` |

### 交互细节与 FAQ

- **按键可以修改吗？** 全局划词、截图及可选追加快捷键都可点击对应按钮后直接按组合键录入；松开主键完成，Esc 取消。追加快捷键进入录入状态后，可点击“清空并停用”或按 Delete 清空，录入或清空均在保存后生效。冲突时会提示；窗口内的二次触发键固定为 `D` / `S`。
- **输入框里的 D / S 会翻译吗？** 编辑文字时正常输入 `D` / `S`；请点击“翻译 / 查询”，或将焦点移出输入框后再用快捷键。
- **按住 D / S 等原文出现，会自动翻译吗？** 不会。原文就绪后需要松开并重新按一次；带 `Option`、`Control` 或 `Command` 的组合键、输入法组合输入和编辑框内的按键不会触发。
- **连按两次捕获快捷键会怎样？** 当前取词或截图未结束时忽略重复请求；翻译框获得焦点后再次按划词快捷键会保留结果。截图完成或取消后，可再次触发。
- **什么内容能收进生词本？** 原文需被识别为英语或手动指定为英语；预览后明确点击“收录”才保存。点击或划选译文不会触发预览或收录。
- **自动提词有什么限制？** 在设置中开启后，模型可为英语原文提供候选；超过 150 词或 800 字符的输入会跳过自动提词，翻译仍可继续。
- **收起侧栏后会自动弹回来吗？** 后续模型元数据不会重新打开手动收起的侧栏；主动在原文重新选词可以打开预览。
- **浏览历史会再次调用模型吗？** 不会；主动点击“重新翻译”才会发起新请求。
- **历史清理会删除什么？** 保留期按创建时间计算；保存较短期限会清理已过期记录，关闭磁盘保存会清理已有历史。删除一条历史会一并删除其原文、截图与译文，确认后不可撤销。已收录词条在生词本中单独管理。
- **“段落模式 / 词典模式”是手动切换翻译方式吗？** 服务设置里的按钮切换默认提示词预览；实际处理模式由输入内容选择。

## 🛡️ 隐私与安全

SensitiveGuard 在捕获文字进入结果窗口和发送给模型前，检查常见英文 BIP-39 助记词、私钥和 API Key 格式；命中后隐藏明文并阻止发送，未放行的内容不写入历史。检测可能误报或漏报，模型译文和 OCR 结果也需要结合上下文核对。

服务密钥仅加密保存在 **macOS 系统钥匙串（Keychain）**，不会写入应用配置或历史数据库。启动时静默读取，不会连续请求授权。主动翻译时，如果已保存密钥需要重新授权，会先说明钥匙串安全存储方式；点击“授权并继续”后，由 macOS 请求访问许可，成功后继续翻译，无需重新输入 API Key。也可在服务设置中点击“授权已保存密钥”。

系统提示的密码通常是 **Mac 登录密码（钥匙串密码）**，不是 API Key，由 macOS 系统授权框处理。已获授权时可能不弹框；每个服务的钥匙串条目独立授权，更新开发签名后的应用可能需要再次授权。保存或删除密钥也可能请求授权，取消授权会保留原密钥和设置。本机 OCR、词典与朗读不需要远程模型；远程翻译会将原文发送给你选择的服务商。问题报告请勿附带密钥或私人捕获内容，安全问题见 [SECURITY.md](../SECURITY.md)。

取消“授权并继续”不会修改原密钥，也不会发送这次翻译。
