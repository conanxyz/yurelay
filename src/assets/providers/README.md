# Provider marks

Bundled monochrome SVG artwork from `@lobehub/icons-static-svg` 1.95.1 (MIT, see LICENSE).
Source: https://github.com/lobehub/lobe-icons

Used for provider identification only. The custom-provider symbol, system-book icon,
and Youdao Chinese-character mark are local Yurelay drawings in ProviderLogo.svelte.
No image requests are made at runtime. These files are static build inputs, not user HTML.
